# 🎬 Netflix Content Analysis & Recommendation Insights

This project focuses on analyzing Netflix content data using Python and data visualization techniques to uncover trends, patterns, and recommendation insights in the entertainment and media domain.

---

## 🚀 Project Overview

The project analyzes Netflix titles data to identify:

- Content growth trends over the years
- Distribution of Movies vs TV Shows
- Regional content distribution
- Relationship between movie duration and release year
- Trend smoothing for content growth analysis

The goal is to generate meaningful insights using data analytics and visualization.

---

## 📊 Features & Analysis

### 🔥 Heatmap Analysis
Visualizes content added over the years categorized by type.

### 🌍 Regional Recommendation Insights
Analyzes top contributing countries on Netflix.

### 🎥 Duration vs Release Year
Scatter plot showing trends between movie duration and release year.

### 📈 Content Growth Trend
Smoothed trend analysis of Netflix content additions over time.
